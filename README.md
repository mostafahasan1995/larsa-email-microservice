# larsa-email-microservice

Email microservice for the Larsa platform, with bulk sending.

**Stack:** Node.js, Express, Nodemailer, MongoDB, Redis, NATS

> Built by the Larsa engineering team and published with the company's permission. My contribution: 22 of 162 commits. This is a clean snapshot: git history is removed and secrets are replaced with placeholders.

## Setup

```bash
npm install
npm start
```
